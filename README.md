# Программа №1 – Вычисление площади треугольника

Пользователь вводит длины трех сторон треугольника. Программа проверяет существование треугольника и вычисляет его площадь по формуле Герона.

## Инструкция по работе
По запросу программы необходимо последовательно ввести три числа — длины первой, второй и третьей стороны треугольника.

# Программа №2 – Конвертер расстояния

Программа конвертирует расстояние из одних единиц измерения в другие. Поддерживаются единицы: м, км, см, мм, mi, yd.

## Инструкция по работе
По запросу программы необходимо ввести:
1. Исходную единицу измерения.
2. Выходную единицу измерения.
3. Количество исходных единиц.
